# 页面跳转审计（2026-09-09）

## 已检查的跳转链

- 大事件 → 时刻详情 → 编辑时刻 → 保存后回到同一详情。
- 大事件/日子簿 →「＋ 新时刻」；新建保存回大事件，返回键回来源页签。
- 日子簿 →「接受新任务」/编辑任务；保存或返回回日子簿，并保留日期选择。
- 日子簿 → 系统设置 → 封印之地；回收站返回系统设置，系统设置返回日子簿。
- 页签切换与系统返回：关闭叠加页并清理 Moment/Task 身份，避免旧 ID 复用。
- `Saver` 进程恢复：未知页签/目的地回退安全状态；详情缺少 Moment ID 时丢弃详情目的地。

## 本轮修复

1. 详情页不再对 `status` 做强制非空断言；状态暂不可用时显示错误提示，不触发闪退。
2. 导航状态恢复不再直接 `valueOf` 未知字符串；无效值回退到首页且不携带详情 ID。
3. `MOMENT_DETAIL` 没有有效 ID 时恢复为无叠加页，避免以空 ID 加载详情。
